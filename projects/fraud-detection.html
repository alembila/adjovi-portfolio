MACHINE LEARNING CASE STUDY

Credit Card Fraud Detection Using Predictive Analytics

Comparing an interpretable baseline with a tree-based model while focusing on rare-event performance and the operational burden of false positives.

Project Overview

Credit card fraud creates financial losses for institutions and customers while increasing the workload of fraud investigation teams. This project uses predictive analytics to identify fraudulent transactions and compares Logistic Regression with Random Forest.

Business Problem

Fraud represents a very small percentage of total transactions. A model can appear highly accurate while still failing to detect fraud. The analysis therefore emphasizes precision, recall, F1-score, ROC-AUC, PR-AUC, and confusion matrices rather than accuracy alone.

Dataset & Preparation

The dataset contains 339,607 transactions and 1,782 fraudulent transactions, producing a fraud rate of approximately 0.525%. Preparation included missing-value review, duplicate checks, data-type corrections, feature engineering, and a stratified train-test split.

Methods

Logistic Regression was used as an interpretable baseline. Random Forest was evaluated to capture nonlinear relationships and interactions among transaction characteristics.

Key Findings

Fraudulent transactions showed different patterns in amount, category, and time of day. Random Forest demonstrated stronger overall predictive performance, while Logistic Regression remained useful as an interpretable baseline.

Business Value & Responsible Use

The model can support investigation prioritization and improve operational efficiency. It should be used as decision support with human review rather than as the sole basis for automatically blocking transactions.

Limitations & Future Work

Fraud patterns can change over time. Future work could include model monitoring, streaming data, behavioral features, and decision-threshold optimization based on investigation capacity.
