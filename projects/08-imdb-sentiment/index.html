IMDB Sentiment Analysis

Compared sentiment-analysis approaches using TextBlob, optional VADER, and custom text preprocessing. The project demonstrates NLP preparation, polarity analysis, and model-oriented text transformation.

Dataset

IMDB review text used for sentiment analysis.

Methods

TextBlob sentiment scoring, optional VADER analysis, and preprocessing for custom modeling.

Key Findings

Shows the difference between lexicon-based sentiment and model-ready text preparation.

Business Value

Useful for customer-feedback analysis while recognizing context, sarcasm and language limitations.
