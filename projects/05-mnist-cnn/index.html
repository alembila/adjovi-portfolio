DEEP LEARNING

MNIST Handwritten Digit CNN

Built a convolutional neural network with TensorFlow/Keras to classify handwritten digits. The notebook documents data loading, preprocessing, CNN architecture, training, evaluation, and interpretation.

Dataset

MNIST handwritten digit image dataset.

Methods

TensorFlow/Keras convolutional neural network with image normalization, training and test evaluation.

Key Findings

The project demonstrates a complete deep-learning image-classification workflow and interpretation of model performance.

Business Value

Shows ability to move from tabular analytics into neural-network computer vision.
